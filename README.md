# TruckSafe Fleet

מערכת לניהול צי משאיות, נהגים, משימות, בדיקות בטיחות, אירועים, תחזוקה ומעקב GPS.

## מודולים
- לוח בקרה ומצב צי
- נהגים וכלי רכב
- משימות ונסיעות
- בדיקת רכב לפני נסיעה ודיווח ליקויים
- מרכז אירועי בטיחות
- תחזוקה ורישומי מגבלות דרך
- מפת מיקומי נהגים, היסטוריית נסיעות ודוחות
- מסך תכנון מסלול למשאיות (מושבת עד להגדרת ספק ניתוב מאושר)

## טכנולוגיה
- Next.js 15 / React 18
- Supabase Auth, PostgreSQL, RLS ו-Storage
- Vercel לפריסה
- עברית ו-RTL, תמיכה במסכים ניידים ושולחניים

## הרצה מקומית
דרישות: Node.js 24.x ו-npm.

```bash
npm install
npm run dev
```

יש להגדיר את משתני הסביבה:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

אין להכניס מפתחות service_role, מפתחות סודיים או סיסמאות למסמכי קוד או לקוד צד-לקוח.

## בדיקות
```bash
npm run test:security
npm run build
```

GitHub Actions מריץ בדיקות אבטחה קלות לייצוא CSV, build וביקורת תלויות, וכן בדיקות SQL מבודדות לתהליך בדיקת טרום-נסיעה, הרשאות, נעילת רכב, תיעוד סגירת אירוע ומעברי סטטוס.

## גבולות בטיחות חשובים
- בדיקת טרום-נסיעה במערכת היא כלי תיעוד ובקרה, ואינה מחליפה בדיקה פיזית, הכשרה, מסמכים תקפים או שיקול דעת של נהג/מנהל בטיחות.
- מעקב GPS בדפדפן פועל רק כל עוד הדף והדפדפן פעילים; אין הבטחה למעקב ברקע כשהאפליקציה סגורה או כשהמכשיר נעול.
- תכנון מסלול למשאית אינו זמין עד להגדרת ספק ומפתח API. מגבלות הדרך שהוזנו במערכת אינן משולבות עדיין בחישוב אוטומטי.
- גם לאחר חיבור ספק ניתוב, אין לראות במסלול הבטחה למעבר חוקי או בטוח. יש לפעול לפי שילוט, הוראות רשמיות, מגבלות משקל/מידות, עבודות בכביש והנחיות גורמי האכיפה.

## סטטוס שחרור
העבודה הנוכחית נמצאת בענף פיתוח וב-PR טיוטה. אין להחיל מיגרציות על מסד הייצור או לפרוס לייצור לפני גיבוי מאומת, בדיקות מלאות, סקירה ואישור שחרור מפורש.
